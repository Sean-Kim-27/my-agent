### 6. 🔁 LLM 호출 재시도/백오프 부재 (신규)

* **현재 상태:** 코드베이스 전체에 `retry`, `backoff` 관련 로직이 전무함 (`grep` 결과 0건). LLM API 호출이 일시적 네트워크 오류(타임아웃, 429, 5xx)로 실패하면 즉시 예외가 전파되어 세션이 중단됨.
* **수정 지시:** `llm/base.py`의 `generate()` 공통 래퍼에 지수 백오프 기반 재시도 로직을 추가할 것 (`tenacity` 라이브러리 사용 권장). 429/5xx/타임아웃만 재시도 대상으로 하고, 4xx(인증 오류 등)는 즉시 실패 처리. 재시도 횟수는 3번 항목의 `AgentConfig.max_retries`와 연동.
