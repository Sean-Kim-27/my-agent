### 5. 🔒 로깅 보안 (Structured Logging) 시크릿 마스킹

> ⚠️ **이미 완전히 구현되어 있음. 원 지시서 항목은 코드베이스 현재 상태를 반영하지 못한 stale한 지시임.**

* **현재 상태:** `logging/logger.py:11`에 `Bearer\s+[A-Za-z0-9_\-\.]{8,}` 정규식 기반 마스킹 필터가 이미 로그 포맷터에 연결되어 있고 (`mask_secrets`, `logger.py:18`), 실제로 로그 메시지·구조화 필드 양쪽에 적용됨.
* **수정 지시:** **추가 작업 불필요.** 굳이 보강한다면 API Key 패턴(`sk-...`, `nvapi-...` 등) 및 OAuth refresh token 패턴을 마스킹 정규식 목록에 추가하는 정도만 검토.
